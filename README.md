---

## 🚀 Development & Deployment Commands

```bash
# Navigate to project directory
cd /Users/rajusharma/.gemini/antigravity/scratch/lotusclue-web

# Run local development server
npm run dev

# Build for production
npm run build

# Deploy to Firebase Hosting (lotusclue.web.app)
npm run deploy
```
